# ⚔️ CodeWars Java Solutions

Este repositório é dedicado à organização e acompanhamento da resolução de desafios (Katas) da plataforma **CodeWars** utilizando a linguagem **Java**.

O objetivo principal é aprimorar o domínio sintático da linguagem, praticar refatoração, utilizar recursos modernos do Java (como Streams e Lambdas) e resolver problemas com foco em código limpo e eficiente.

---

## 📁 Estrutura e Padronização do Repositório

As soluções são organizadas conforme os níveis de dificuldade da plataforma (*Kyu*), onde cada arquivo contém:

1. **A Resolução do Kata:** Classe com o método responsável por resolver o desafio conforme estipulado.
2. **O Método de Teste (`main`):** Estrutura local com chamadas e asserções básicas para testar o comportamento do código diretamente no console da IDE.

A distribuição de pastas segue a hierarquia dos Katas:

```text
├── src/
│   ├── kyu8/
│   ├── kyu7/
│   ├── kyu6/
│   └── kyu5/
└── README.md
```

---

## ⚙️ Como Executar os Testes na IDE

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/lxzinxs/codewars-java-solutions.git
   ```

2. **Abrir o Projeto:**
   * Importe o projeto para a sua IDE de preferência.
   * Certifique-se de que o **JDK** esteja configurado adequadamente.

3. **Executar um Exercício:**
   * Abra a classe correspondente ao Kata desejado.
   * Execute o método `main` para verificar os resultados das chamadas de teste diretamente no terminal.
